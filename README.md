# University Club & Event Management System

A relational database system designed to manage university clubs, memberships, events, resources, and financial transactions.

## Project Overview
This system centralizes how student organizations manage:
- Club memberships
- Event scheduling and attendance
- Resource reservations
- Financial transactions

It replaces fragmented spreadsheets and manual tracking with a normalized relational database.

## Business Problems Solved
- Which clubs are most active?
- Which members are most engaged?
- How much revenue and expense is tied to each event?
- Which resources are overused or underutilized?

## Database Design
The system is built using a fully normalized 3NF relational schema including:
- Clubs
- Members
- Events
- ClubMemberships
- EventAttendance
- Resources
- EventResourceReservations
- Transactions
